构建继承账本 · 示例

构建面板原来把每个来源打印成绝对路径，单个任务看不出继承链，整批任务看不出分布。现在路径按项目根相对显示，每个文件标注继承 / 覆盖 / 指定 / 缺失，批次层面用叠条给出分布，×N 表示有多少任务共用同一来源。

示例数据由 src/client/inheritance.ts 实时计算 样式取自 src/client/presentation.ts 面板宽度 420px，与右侧 dock 一致
