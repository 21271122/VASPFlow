# `vasp_compare_inputs`：跨目录输入比较设计

对应演示：[比较卡片 Demo](vaspflow-compare-inputs-card-demo.html)。本文件是工具和卡片设计；当前版本不注册 `vasp_compare_inputs`，演示使用虚拟数据，不读取或修改计算目录。

## 目的和边界

把多个任务或模板目录的输入差异变成可定位的证据。重点回答：哪些 INCAR 参数始终相同、哪些参数有多个取值、每个 INCAR 版本出现在哪些目录、标准输入文件的覆盖情况如何。目录只需包含待比较的文件，不必先被识别为完整 VASP 任务。

比较工具只报告文件与参数差异，不宣称某个设置科学上等价、合理或可直接提交。`vasp_check_inputs` 仍负责规则校验，`vasp_inspect_tasks` 仍负责计算状态。

## 建议输入

```json
{
  "rootPath": "D:\\Projects\\VASPFlow\\test",
  "dirs": ["1-NO3", "2-NO", "8-NO-scan/dz-p0.2"],
  "include": ["INCAR", "KPOINTS", "POTCAR", "POSCAR"]
}
```

- `rootPath` 是绝对比较根目录；`dirs` 是相对目录，1–200 项。只读取所列目录的直属文件，不递归寻找子任务。父目录搜索由扫描/发现工具先完成，避免一次比较意外扩展到整棵树。
- `include` 缺省为四种标准输入。某目录缺少某文件时记为“未提供”，保留该目录的其他比较结果。
- 工具固定忽略 `SYSTEM` 对 INCAR 版本划分的影响；原值仍可在目录详情中查看。没有供用户取消的开关，避免任务专属名称把每个目录都拆成独立版本。

## 解析与归并

1. INCAR 标签名统一大写；忽略空白、注释和赋值顺序。数值的等价写法统一表示，例如 `1E-4` 与 `0.0001`。重复赋值按最后有效赋值比较，同时报告重复标签。
2. **INCAR 版本**：除 `SYSTEM` 外，所有已解析 INCAR 标签和值相同才归为一版。缺失字段与显式赋值不同；不能凭 VASP 默认值猜测等价。EDIFF、EDIFFG、NSW 的不同数值始终是不同版本。这是文本参数归并，不代表科学上的输入等价。
3. **变化参数**：遍历全部已解析的 INCAR 标签，凡在所选目录中出现多个值（包括“未设置”）都展示分布；值相同的参数收在“全部目录相同”一栏。不能预设只比较 EDIFF、EDIFFG、NSW。
4. KPOINTS 展示模式及网格，POTCAR 展示物种顺序，POSCAR 展示物种、原子数和 SD 标志概况。这些是附加差异列，不混入 INCAR 的组合计数，也不解析或回传完整 POTCAR 正文。
5. 解析失败、文件缺失、重复标签和物种顺序不一致分别给出路径与证据。一个目录异常不终止其他目录。

## 建议结果契约

```json
{
  "rootPath": "...",
  "scope": { "dirsRequested": 108, "dirsRead": 108, "ignoredKeys": ["SYSTEM"] },
  "summary": { "incarVersions": 36, "variableKeys": ["EDIFF", "EDIFFG", "NSW"], "directoriesToReview": 8 },
  "coverage": { "INCAR": 108, "KPOINTS": 102, "POTCAR": 108, "POSCAR": 84 },
  "distributions": [{ "key": "EDIFF", "values": [{ "value": "1E-3", "count": 36 }] }],
  "versions": [{ "id": "v1", "count": 3, "varyingParameters": {}, "dirs": ["..."] }],
  "entries": [{ "dir": "1-NO3", "files": {}, "incar": {}, "warnings": [] }]
}
```

模型可见的 `render()` 只给根目录、数量、变化最多的参数、异常目录及可继续缩小范围的建议；不要把全部 `entries` 或 36 个版本打印给模型。卡片使用结构化结果；大结果可以由 `comparisonId` 分页获取。

## 卡片交互

- **首屏**：参与比较的目录数、INCAR 版本数、变化参数数、需查看的目录数，每个数字下面写明计数口径；随后展示四种标准输入文件的覆盖数。
- **参数分布**：从全部已解析标签中找出变化项，每个值有数量条。点击值交叉筛选，顶部显示当前筛选条件与剩余目录数。`SYSTEM` 固定不参与版本划分，用户仍可查看原值。
- **INCAR 版本列表**：这是可点开的表格，不称“矩阵”。一行代表一个版本，列只显示变化参数；固定参数收进“全部目录相同”摘要。点击一行显示目录路径及文件提示；数量过多时分页。
- **目录树**：有根目录，可按路径层级展开；点击目录显示其 INCAR 全量差异、KPOINTS/POTCAR/POSCAR 摘要及原文件路径。展开规则沿用现有工具树：只保留当前直系上游，收起父目录时一并收起后代。
- 卡片支持折叠成一行；筛选、视图、树状态在折叠后保留。键盘可切换视图，所有筛选可通过按钮完成，颜色之外还显示文字与数量。

## 验收样例

对 108 个目录进行比较，其中 36 种 EDIFF × EDIFFG × NSW 版本各有 3 个目录，且每个目录的 `SYSTEM` 都不同。结果应为“108 个目录、36 个 INCAR 版本、3 个变化参数”；没有把 `SYSTEM` 加回版本键的 UI 开关。点击任一参数值后，版本列表和目录树同时缩小，并能追溯每一个目录的相对路径。
