# VASPFlow 工具结果统一渲染方案

## 范围与现状

VASP Agent 当前注册 7 个 `vasp_*` 工具。`vasp_build_inputs` 已使用对话内任务树；其余工具仍显示 DSH 通用工具视图。源码中的 `vasp_task_files`、`vasp_read_file`、`vasp_scan_templates` 均被 `if (false)` 禁用，不纳入本轮方案。

统一的是**信息层级和交互语言**，不是让每种结果都长成同一张卡片。工具结果直接嵌入对话，不再增加外层卡片；右侧看板承载详细内容。

## 共用规则

1. **首行即结论**：工具名对应的中文动作、对象、结果状态和关键数量在一行内读完。例如「输入检查 · 11/11 通过 · 批次一致」。执行中、完成、警告、失败均使用文字；颜色只作辅助。
2. **批量结果只展开有用的行**：默认显示异常任务和最多少量代表项；其余用「查看全部 N 项」展开。单个任务的行可直接点击。避免把模型已经读过的长文本、JSON、坐标数组和文件内容复制进对话。
3. **详情有明确归属**：任务、曲线、结构、文件点击后打开右侧看板相应页签；构建任务继续打开现有构建详情。结构源和模板候选尚无看板视图，先在对话内展开来源、完整性和关键参数，不做看似可点击却无去处的行。
4. **历史结果与当前状态分开**：对话中的计数和状态来自该次工具调用的快照，切换对话后保持原样；右侧看板若重新读取磁盘，标明它展示的是当前状态。点击历史结果不自动重新执行工具或写入文件。
5. **操作只出现在能操作的结果上**：读类工具只有「查看」；`vasp_build_inputs` 的预览才有勾选、取消和确认。确认、取消、失败后的状态按 `planId` 保持，不能因对话切换重新出现可用按钮。
6. **同一视觉语法**：无阴影和层层矩形框；一行任务约 32–36 px，选中行用浅色背景。统一状态文字、间距、分组缩进、键盘焦点和暗色主题。错误紧贴对应行，不能仅靠颜色辨识。

## 七个工具的映射

| 工具 | 对话中的默认呈现 | 点击后的详情 |
| --- | --- | --- |
| `vasp_scan` | 「扫描项目 · N 个任务 · 运行 X / 错误 Y」；仅列异常与运行中的任务，可展开全量树 | 点击任务打开看板「状态」；普通目录只展示名称，不伪装成 VASP 任务 |
| `vasp_inspect_task` | 「核查任务 · 路径 · 状态」；下一行只放导致该状态的关键证据或错误 | 打开对应任务的「状态」或「文件」；请求了文件预览时优先打开文件 |
| `vasp_convergence` | 「收敛数据 · 路径 · N 个离子步 · 末步能量」；无数据时说明原因 | 打开该任务的完整「收敛」曲线，不在对话渲染完整数值数组 |
| `vasp_structure_scene` | 「结构 · 文件名 · 化学式 · N 原子」；解析警告单独显示 | 打开「结构」3D 视图；不在对话渲染原子和键的 JSON |
| `vasp_discover_inputs` | 「发现输入 · N 个结构源 / M 个模板 · 一致性状态」；源与模板分两组，冲突项优先 | 先在对话展开候选的路径、文件完整性和关键参数；后续若新增候选详情页再迁入看板 |
| `vasp_build_inputs` | 保留现有紧凑任务树；首行明确「预览未写入」或「已写入 X/Y」；只显示当前可执行的操作 | 点击任务打开现有构建详情；确认结果在对话切换后保持 |
| `vasp_check_inputs` | 「输入检查 · 通过 X / 警告 Y / 失败 Z · 批次一致/不一致」；默认只列失败、警告和不一致组 | 点击目录打开任务「状态」中的输入检查详情；保留检查规则名称 |

## 实施边界

- 七个工具共用一套行标题、状态标记、分组列表和看板跳转函数；各工具只负责把自己的结构化结果映射成这些元素。不要建立包含七套条件分支的巨型组件。
- 扩展 `tool.call.toolview` 注册到其余六个工具。保留宿主现有的 `output.render`，因为它是给模型阅读的；为界面补充精简的 `presentationMeta`，不要从中文文本反向解析数据，也不要把完整结构场景塞进元数据。
- 用 `rootPath + relPath` 关联任务，不依赖会话内临时 `taskId`。数据缺失或历史任务已不存在时，展示原始调用快照和明确错误，不静默跳到别的任务。

## 验收场景

- 扫描 100 个任务时对话首屏仍是摘要，能展开并定位异常任务。
- 选择收敛或结构结果后，看板打开正确任务和页签；对话不出现原始数组或 3D JSON。
- 输入检查的批次不一致清楚可见；通过任务不会淹没异常项。
- 预览确认、取消或失败后切换对话再返回，按钮状态与结果不回退。
- 键盘可打开每一行，状态在明暗主题下均可读，错误不依赖颜色表达。
